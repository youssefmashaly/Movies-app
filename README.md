# 🚀 Getting Started

## Requirements

- Node.js 20+
- npm

Install dependencies

```bash
npm install
```

Create your environment file

```bash
cp .env.example .env
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

# 🔑 Environment Variables

See `.env.example`.

Required

- Firebase credentials
- Supabase URL
- Supabase Anon Key

Optional

- GEMINI_API_KEY
- VITE_ANALYTICS_ENABLED
- VITE_ANALYTICS_ENDPOINT

Never commit your real credentials.

---

# 📦 Production

Build

```bash
npm run build
```

Run

```bash
npm start
```

# ☁ Deployment

Supported

- Render
- Railway
- Fly.io
- Google Cloud Run
- Vercel
- Netlify

The project includes serverless adapters for both **Vercel** and **Netlify**, while the same Express application powers traditional Node deployments.

---

# 📊 Analytics

A lightweight analytics utility is included but disabled by default.

Enable by setting

```
VITE_ANALYTICS_ENABLED=true
```

and providing

```
VITE_ANALYTICS_ENDPOINT
```
